位置编码

1. 位置编码简介

位置编码是指对于一个token，将其在上下文中的位置信息编码为一个向量，以便模型可以利用位置信息进行计算。

那么为什么需要在transformer中使用位置编码？按理说在attention中，距离越远的token对当前token的贡献会越小，但是attention本身的计算过程无法直接识别token的远近，因此引入位置编码会帮助模型更好地理解token之间的关系。

核心思想：一个好的位置编码应该满足以下条件
（1）每个位置有唯一的编码
（2）具备良好的外推性
（3）内积只和相对位置有关，且相对位置越远，内积越小

方法 外推倍数（大致） 修改幅度 实现难度 主流代表模型/项目 备注
原生 RoPE 1.5~3× 无 最低 LLaMA-2/3 原始 基准线
Position Interpolation (PI) 4~8× 小 低 LLaMA-2 长上下文版本 简单有效，但有上限

2. 绝对位置编码

$$emb_{new}(token) = concat(emb_{old}(token), pe(pos))$$

其中，$emb_{old}(token)$是token的原始embedding向量，$pe(pos)$是token的位置编码向量，例如one-hot编码。两者拼接得到新的embedding向量。

缺点：

当推理时的文本长度超过了模型预训练时的长度，就会超出模型的位置编码范围，导致位置编码失效。因此，绝对位置编码不具有外推能力，在后来的transformer中提出了具有外推性的正弦位置编码。

3. 正弦位置编码

$$emb_{new}(token) = emb_{old}(token) + pe(pos,i)$$

其中，位置编码$pe(pos, i)$既与token的位置$pos$有关，也与token的embedding维度$i$有关。具体来说，对于一个序列pos（从0开始）和嵌入维度$i$（从0到$\frac{d}{2}$），位置编码$pe(pos, i)$的计算如下：

$$
pe(pos, 2i) = \sin(\frac{pos}{10000^{2i/d}}) \
pe(pos, 2i+1) = \cos(\frac{pos}{10000^{2i/d}})
$$

优点

可以看到，$sin$和$cos$函数的定义域是$R$，因此即使推理时的文本长度超过了模型预训练时的长度，位置编码也能够外推到新的位置。

缺点

正弦位置编码只能间接地让模型学到“距离越远贡献越小”的偏置，无法像后来的相对位置编码ROPE或 ALiBi 那样，在注意力计算中显式地、确定性地引入随相对距离单调衰减的机制。

4. ALiBi（Attention with Linear Biases，注意力线性偏置）

ALiBi 是 2021 年提出的一种极简位置信息注入方法，它完全不修改 token 的 embedding，而是直接在注意力计算的 logits（即 QKᵀ/√d 之后、softmax 之前）加上一个与相对距离成正比的线性偏置。

核心公式（以 causal 自回归模型为例，第 h 个注意力头）：

$$
\text{logits}_{i,j} = \frac{q_i \cdot k_j}{\sqrt{d_h}} - m_h \cdot (i - j) \quad (j \leq i)
$$

其中：

  • $i$ 是 query 的位置，$j$ 是 key 的位置（$j \leq i$）
  • $m_h > 0$ 是第 h 个头的固定斜率（slope），通常按几何级数设置，例如 $m_h = \frac{1}{2^{0.5 \times h}}$ 或类似变体
  • 距离 $(i - j)$ 越大，减去的惩罚越大 → 远的 token 注意力分数被显著压低

不同头有不同 $m_h$：前面的头 $m_h$ 接近 0（允许关注较远的位置），后面的头 $m_h$ 较大（强烈偏好局部、最近的 token），让模型天然具备多尺度注意力范围。

优点

  • 极强的长度外推能力：在较短序列（如 1024 或 2048）上训练后，推理时可直接处理数倍甚至十倍长的序列，perplexity 基本不崩（远超原始正弦位置编码）
  • 实现极其简单、无额外参数：不增加 embedding 维度，不引入可学习参数，只需在 attention mask 或 logits 上加一个下三角 bias 矩阵
  • 训练更快、显存更省：相比加位置向量的方案，计算和内存开销更小

缺点

  • 引入了很强的越远越不重要归纳偏置（recency bias），对需要精确捕捉超长距离依赖的任务可能不如更灵活的方法（如 RoPE）
  • 在极长上下文（数十万 token）微调场景下，后来的 NTK-aware RoPE、YaRN 等组合往往表现更好
  • 对双向模型（encoder-only，如 BERT 类）适配性较弱，主要在 decoder-only 语言模型上表现出色

5. RoPE（Rotary Position Embedding，旋转位置编码）

RoPE 是 2021 年提出的位置编码方法，目前已成为 LLaMA、Qwen、Gemma、Mistral 等绝大多数现代大模型的默认选择。它不向 embedding 加额外向量，而是直接对 query 和 key 向量施加位置相关的旋转，让注意力内积天然编码相对位置信息。

核心思想：将 embedding 的维度两两配对（pair），每个 pair 视为一个 2D 向量，然后根据位置 m 施加一个旋转矩阵。

对于位置 m 的 token，其 query 向量经过旋转后：

$$
\mathbf{q}_m’ = \mathbf{R}_m^d , W_q \mathbf{x}_m
$$

其中旋转矩阵 $\mathbf{R}_m^d$ 是块对角矩阵（block-diagonal），每个 2×2 块为：

$$
\begin{pmatrix}
\cos(m\theta_i) & -\sin(m\theta_i) \
\sin(m\theta_i) & \cos(m\theta_i)
\end{pmatrix}
\quad \text{作用于维度 (2i, 2i+1)}
$$

旋转角度 $\theta_i$ 的经典设置（与正弦位置编码类似）：

$$
\theta_i = 10000^{-2i/d} \quad i = 0,1,\dots,\frac{d}{2}-1
$$

key 向量同理旋转：

$$
\mathbf{k}_n’ = \mathbf{R}_n^d , W_k \mathbf{x}_n
$$

注意力分数（内积）变为：

$$
\mathbf{q}_m’^T \mathbf{k}_n’ = (W_q \mathbf{x}_m)^T \mathbf{R}_m^d{}^T \mathbf{R}_n^d (W_k \mathbf{x}_n)
$$

由于旋转矩阵的性质，$\mathbf{R}_m^d{}^T \mathbf{R}n^d = \mathbf{R}{m-n}^d$，所以最终内积**只依赖相对距离 (m - n)**：

$$
g(\mathbf{x}_m, \mathbf{x}_n, m-n) = (W_q \mathbf{x}m)^T \mathbf{R}{m-n}^d (W_k \mathbf{x}_n)
$$

这正是 RoPE 的天才之处：相对位置信息被直接编码进了 QK 内积，而不需要额外 bias 或可学习参数，且具有远程衰减的性质。

优点

  • 天然的相对位置偏置：注意力分数显式依赖相对距离 (m-n)，比正弦位置编码的“间接学习”更强、更确定性
  • 优秀的长度外推能力：在训练长度内表现优秀，超出训练长度后衰减较缓（结合 NTK-aware、YaRN 等微调后可轻松外推到 32k、128k 甚至百万级）
  • 无额外参数、计算高效：旋转操作只需少量乘法 + 加法，可与线性投影融合实现
  • 兼容性极强：适用于各种注意力变体（FlashAttention、Group-Query 等）

缺点

  • 原始 RoPE 在极长序列（>训练长度的 4–8 倍）时仍会衰减。在embedding的维度上，当$i$较小时，角度$m*\theta_i$随着位置m的增加变化的非常快，当$i=1$时，$m$大于6时就走过了一个周期，但是当$i=\frac{d}{2}$时，$m$大于62800才会走过一个周期，这就会导致在外推时模型没见过极端大的旋转角度组合，因此需要额外技巧（如动态 NTK、PI、YaRN）来缓解
  • 对角度基数（base=10000）的敏感性较高，不同模型常需微调 base 值
  • 理论上引入了周期性（与正弦类似），但实际中影响较小

一句话总结：RoPE 通过在向量空间里“旋转” query 和 key，让注意力分数天然带有相对距离依赖，是目前最平衡、最广泛采用的位置编码方案，几乎成了现代 decoder-only 大模型的“工业标准”。

5.1. 线性内插（Position Interpolation, PI）

PI 是 2023 年提出的 RoPE 长度外推方法，核心思路非常简单：不改 RoPE 的频率 θ_i，而是把目标长序列的位置索引线性压缩回原始训练长度范围，让所有位置的旋转角度保持在模型“见过”的区间内。

核心思路： 假设原始训练长度 L，目标长度 L’（L’ > L），对于推理时的位置 m’（0 到 L’-1），映射到：

$$
m = m’ \times \frac{L}{L’}
$$

然后用这个压缩后的 m 计算旋转矩阵：

$$
\mathbf{R}_m^d \quad \text{（其余 RoPE 计算不变）}
$$

等价于把相对距离 (m’ - n’) 整体缩放为 (L/L’) × (m’ - n’)。

优点

  • 实现极简、无需改频率结构、无额外参数
  • 微调友好：通常只需 100–1000 步少量数据微调，就能让 perplexity 恢复良好，并在长上下文任务（如 passkey retrieval、长文档总结）上表现强劲
  • 理论稳定：插值上界远小于外推（论文证明 ~600× 更稳定），避免注意力分数灾难性爆炸

缺点

  • 统一压缩导致高频维度（小 i）旋转被过度“挤压”，高频位置信息丢失严重，模型分辨细粒度相对位置的能力下降
  • 外推倍数有限：纯 PI + 微调通常上限在 4–8×，再高 perplexity 容易崩

5.2 NTK-aware Scaled RoPE（NTK 感知缩放 RoPE）

NTK-aware Scaled RoPE 是 2023 年提出的方法，灵感来自 Neural Tangent Kernel（NTK）理论。它不压缩位置索引，而是放大 RoPE 的基数（base），让频率分布整体“变稀疏”，从而在外推时高频维度不过快振荡、低频维度有更多区分空间。

核心思路：动态或静态放大 base（原 10000）：

原始RoPE频率

$$θ_i = base^{−2i/d}$$

NTK缩放后频率

$$θ’_i = (base·s^{d/(d-2)})^{−2i/d} = base^{−2i/d} · s^{−2i/d}$$

  • s = 新长度 / 训练长度（缩放因子，如 4k→16k 则 s=4）
  • 等价于：$base’ = base · s^{d/(d−2)}$（非线性增大基数）

优点

  • 相对于线性插值，高维频率不会被过度挤压，可以保住高频信息；低维频率也会被压缩，可以提升模型捕捉远距离语义信息（段落间）的能力。

5.3 YaRN（Yet another RoPE extensioN method）

YaRN 是 2023 年提出的高效上下文窗口扩展方法。它在 NTK-by-parts（NTK 分段插值）的基础上，结合 注意力温度缩放（attention temperature scaling），大幅提升 RoPE 在长序列上的外推能力。

核心思路：

  1. 分段频率缩放（Piecewise Frequency Scaling，基于 NTK-by-parts）
    对 RoPE 的频率 θ_i 进行分段处理：

    • 低频维度（大 i，周期长）：采用插值（类似 PI 或 NTK-aware 的温和缩放），让角度变化更平滑，避免远位置旋转过小。
    • 高频维度（小 i，周期短）：采用外推（保留或轻微缩放），防止过度周期振荡。
      具体实现通常用一个“ramp”函数（线性或 harmonic mean）在低/高频间过渡：
      $$
      \theta_i’ = \theta_i \times s^{h(i)}
      $$
      其中 s 是扩展因子，h(i) 是维度 i 的缩放强度（低频 h(i) 接近 1，高频 h(i) 接近 0）。

  2. 注意力温度缩放（Attention Temperature）
    在注意力 logits 上引入温度 t > 1：
    $$
    \text{attention weights} = \text{softmax}\left( \frac{q_m^T k_n}{t} \right)
    $$
    等价于把旋转 embedding 的幅度整体缩放 √(1/t)，让注意力分布更“平滑”（减少极端注意力集中），显著降低长上下文下的 perplexity 上升。
    这个 trick 零开销（预计算 rotary embeddings 时乘 √(1/t) 即可），推理/训练都不改代码。

YaRN 通常结合少量长上下文微调（只需 400–600 步，10x 更少的 token 和 2.5x 更少的训练步数）即可实现。

优点

  • 极高效：比 PI/NTK-aware 节省大量计算资源，却达到或超过 SOTA 性能
  • 强外推能力：LLaMA 系列在微调后轻松达到 32k、64k、128k 甚至更高，perplexity 保持稳定；还能外推到微调数据集未见过的长度
  • 兼容性极好：作为 drop-in replacement，几乎不影响短上下文表现；已成为许多开源长上下文模型（如 Nous-Hermes、一些 LLaMA-2/3 变体）的 baseline
  • 零额外参数：只改 RoPE 计算和温度，无需引入 bias 或新模块

缺点

  • 需要少量微调才能达到最佳效果（纯零样本不如 Dynamic NTK 强，但结合微调后远超）
  • 分段缩放和温度 t 的超参（ramp 形状、t 值）需经验调优（不同模型/目标长度不同）
  • 在极长（如 1M+）时，仍需与其他技巧（如 Ring Attention、FlashAttention-2）组合

一句话总结：YaRN 把 NTK-by-parts + 注意力温度缩放结合，用极低的微调成本实现了 RoPE 的“高效长上下文工业标准”，是 2023–2025 年开源社区最受欢迎的 RoPE 扩展方案之一，许多 128k+ 模型都直接或间接基于它。
